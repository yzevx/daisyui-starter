# DaisyUI Starter

English | [简体中文](README.zh-CN.md)

A frontend starter project built with **React, Webpack, Tailwind CSS, and DaisyUI**, designed for use with [**Code App**](https://thebaselab.com/code).

## Getting Started

Open a terminal in the project directory and install the dependencies:

```bash
npm i
```

Start the development server:

```bash
npm run dev
```

Then open the following URL in **Safari**:

```text
http://localhost
```

## Common Commands

| Command | Description |
| --- | --- |
| npm run dev | Start the development server |
| npm run build | Build the project for production |
| npm run format | Format the project with Prettier |

## Project Structure

```text
.
├── src/                 # Source code
├── public/              # Static assets
├── scripts/
│   ├── dev.js           # Development server
│   └── build.js         # Production build
├── .babelrc             # Babel configuration
├── .prettierrc          # Prettier configuration
├── webpack.config.js    # Webpack configuration
├── postcss.config.js    # PostCSS configuration
└── tailwind.config.js   # Tailwind CSS configuration
```
